# Password Generator

GUI application to generate customizable passwords. You can specify the following options:

- Uppercase
- Lowercase
- Numbers
- Symbols
- Custom Length

## Installation

Download the latest release for your operating system from the [Releases](https://github.com/DeimosHall/random-passwords/releases) page.

## Development Setup

1. Install Rust

[Follow the official documentation](https://rust-lang.org/tools/install/).

2. Clone this repository.

Using SSH:

```bash
git clone git@github.com:DeimosHall/random-passwords.git
```
Using HTTPS:

```bash
git clone https://github.com/DeimosHall/random-passwords.git
```

3. Go to the project.

```aiignore
cd random-passwords/
```

4. Build and run the application.

```bash
cargo run
```
